# Meus Sites Favoritos 🌐

Este é um projeto simples desenvolvido em HTML para organizar e exibir uma lista com meus sites favoritos de acesso diário, incluindo links diretos e ícones representativos.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica das páginas.
- **CSS3**: Estilização básica, centralização de elementos e organização em blocos.

## 🔗 Sites Listados

- **GitHub** — Plataforma de hospedagem de código e portfólio.
- **YouTube** — Plataforma de vídeos e entretenimento.
- **X (Twitter)** — Rede social de notícias e atualizações.
- **Gmail** — Serviço de e-mail e comunicação.
- **Spotify** — Plataforma de streaming de música.
